An offline web app that is the best guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a checklist saved in the browser with export and import, filters by kind, a spoiler setting that hides story trophies until they are earned, a roadmap to the platinum, missable trophies flagged, and a guide to each trophy in our own words that cites its sources.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide works with the network off.
